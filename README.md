# MAC0213 - Guilherme Ryuji Osato (14576412)
## Descrição 
Este repositório serve para registrar as atividades do projeto "Soluções digitais no manejo de trombose em pacientes oncológicos", submetido como proposta para a matéria MAC0213 - Atividade Curricular em Comunidade.
O projeto faz parte do 1º Programa de Residência Tecnológica em Saúde Digital (https://residencia.oceanbrasil.com/). 
Esse programa tem como objetivo estimular a colaboração de estudantes de todo o campus da USP para criar soluções para problemas em saúde digital.
O meu grupo em específico está trabalhando com o ICESP para desenvolver uma aplicação que facilite a prescrição de anticoagulantes para tratar trombose em pacientes com câncer. 
Assim, pretende-se minimizar o número de erros cometidos nesse processo. O programa começou em maio, e já passou pela etapa de exploração do problema. 
Atualmente, o projeto está na fase de desenvolvimento do sistema com base em metodologias ágeis (SCRUM).
